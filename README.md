# Android AI UI Designer

A working Android app for AI-assisted UI design using Jetpack Compose.

## Features
- Drag-and-drop UI components
- AI suggestions for layout improvements
- Material 3 design
- Export designs as XML

## Tech Stack
- Kotlin
- Jetpack Compose
- Material 3
- Coroutines & StateFlow

## Getting Started

1. Clone the repo
```bash
 git clone https://github.com/Farhan009-gif/android-ui-designer-ai.git
```
2. Open in Android Studio
3. Run on emulator or device
